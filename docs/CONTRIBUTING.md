## PR 규칙

- PR 본문에 What/Why/How와 `Closes #이슈번호`를 넣는다
- 리뷰 1명 승인 뒤 작성자가 병합한다

## 코드 리뷰 규칙

- 'LGTM'만 적지 않는다. 줄을 지정해 질문·대안·위험을 1개 이상 적는다
- 작성자는 코멘트를 커밋이나 답글로 반영하고 스레드를 Resolve한다
